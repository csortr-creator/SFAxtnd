# SFAxtnd 1.1.1

Изменения относительно опубликованного релиза **1.1.0**.

## Импорт подписок

- Добавлено преобразование серверов из **Clash/Mihomo YAML и JSON**, а также **Xray JSON**. Расширен импорт ссылок, включая TUIC и AnyTLS, обычные и Base64-списки, QR-коды и файлы.
- Каждый сервер проверяется отдельно парсером и ядром. Некорректная запись больше не срывает импорт всей подписки: пригодные серверы сохраняются, причины пропуска попадают в отчёт. Если пригодных серверов нет, существующий профиль не заменяется.
- Исправлены декодирование Shadowsocks и проверка метода шифрования. Параметры, которые нельзя корректно перенести в ядро, отклоняются явно.
- Исправлен импорт **Hysteria 2 из Xray-конфигураций** с `hysteriaSettings`. Поддерживаются закрепление сертификата `pcs`, отдельные имена проверки `vcn` и совместимые параметры `fm` / `finalmask.quicParams` для BBR.
- Исправлен импорт XHTTP из AkresWL: `downloadSettings: null` и другие допустимые пустые поля экспорта обрабатываются как отсутствие настройки. Два сервера со строк 10 и 12 больше не пропускаются по этой причине.

## XHTTP и ядро

- Добавлены ограниченные параллельные POST для XHTTP с параметром `scMaxConcurrentPosts`, корректной нумерацией запросов и отменой незавершённых операций.
- Добавлено дополнительное **VLESS Encryption** для профилей `mlkem768x25519plus.native.0rtt` и `native.1rtt` с одним X25519- или ML-KEM-768-ключом. Режим и ключ сохраняются при импорте ссылок и Xray/Clash-конфигураций.
- Проверены обмен с Xray, повторные и одновременные соединения, все три режима XHTTP, проверка сертификатов и отклонение повреждённых зашифрованных данных. Неподдерживаемые профили шифрования и сочетание с Vision отклоняются явно.

## Интерфейс подписок

- Отчёт появляется **диалогом после ручного импорта или обновления**. При обновлении всех подписок результаты объединяются; отображаются формат, число полученных и импортированных серверов, пропуски и предупреждения.
- В верхней панели подписок доступны кнопки добавления и обновления всех подписок. Убрано меню «Элементы главной страницы» и отдельный пункт отчёта из меню подписки.
- Повторное нажатие во время обновления не запускает ещё одну операцию.

## Фоновая работа

- Опрос статистики и обновления таймера интерфейса прекращаются, когда приложение неактивно, экран выключен или устройство находится в Doze. При возвращении время соединения пересчитывается.
- Скорость в уведомлении обновляется раз в три секунды; одинаковый текст не публикуется повторно. При выключенном экране и в Doze служебный опрос уведомления прекращается.
- Журнал получает события только при открытом экране логов; буфер паузы ограничен 3000 строками.
- Автообновление подписок ожидает подключённую сеть и корректно обрабатывает отмену. Состояние Doze учитывается также при запуске и перезагрузке службы.
- Исправлен расчёт скорости передачи для разных интервалов опроса. Обновлён README с описанием установки, настроек и возможностей импорта.

## Проверки

- 109 JVM-тестов импорта и вспомогательной логики.
- Нативные проверки конфигураций, DNS и совместимости с Xray, включая запуск с детектором гонок.
- На проверенных снимках подписок: **Akres — 551/551**, **AkresWL — 72/72**, без пропусков. Содержимое подписок может меняться; проверка импорта не подтверждает доступность удалённого сервера.

Для большинства современных Android-устройств выбирайте **arm64-v8a**. Версия приложения — **1.1.1**, код версии — **112**. После установки обновите подписки, чтобы добавить серверы, которые предыдущая версия пропускала.
