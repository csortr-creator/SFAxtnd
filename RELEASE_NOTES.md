# SFAxtnd 1.1.3

Изменения относительно опубликованного релиза **1.1.1**.

## Переключение подписки и VPN

- При смене подписки с активным VPN выполняется полный цикл: остановка → освобождение старого Android TUN FD → старт с новым профилем.
- UI не снимает блокировку перехода, пока runtime не дойдёт до `Started` или явной ошибки; при сбое выбранная подписка откатывается.
- Перезапуск VPN после смены настроек больше не обрывается на промежуточном статусе `Starting`.
- Диагностические события в logcat: фильтр `SFA.Switch` (`SELECT_REQUEST` → `STOP_OLD` → `OLD_STOPPED` → `START_NEW` → `CONNECTED`).

## Импорт и XHTTP

- Импорт `x_padding_bytes` из ссылок XHTTP; согласованные значения в `extra` принимаются, противоречащие отклоняются.
- Сохранены и расширены импорт Clash/Mihomo, Xray JSON, TUIC, AnyTLS, Hysteria 2 (pcs/vcn/finalmask), VLESS Encryption (в т.ч. ML-KEM профили).

## Rule-set / SRS

- Загрузка удалённых наборов: сначала напрямую, при ошибке — повтор через прокси выбранного профиля.
- Таймауты 15 с (direct) и 30 с (fallback); отмена не запускает повтор; рабочий кеш сохраняется при неудачном обновлении.

## Прочее с 1.1.1

- Параллельное обновление подписок, отчёты импорта, фоновый опрос с учётом Doze, пресеты маршрутизации и DNS fallback — без регрессии относительно 1.1.1/1.1.2.

## Установка

Для большинства устройств выбирайте **arm64-v8a**. Версия в приложении: **1.1.3**, versionCode **114**.

Ядро: sing-box **1.14.2** с локальными патчами (XHTTP, VLESS encryption, rule-set fallback, ping/probe).
