Реорганизация главного экрана

- Переделана нижняя навигация (убран раздел Маршруты из BottomNav, теперь там 4 таба: Серверы, Подписки, Маршруты, Настройки)
- Экран "Серверы" (раньше Dashboard) теперь содержит только список серверов (GroupsCard).
- Экран "Подписки" (раньше Groups) теперь содержит только список подписок (ProfilesCard).
- Добавлена сортировка серверов по пингу. Кнопка сортировки доступна в TopAppBar на экране Серверов.
- Информация об устаревании (Deprecated) убрана из основного флоу и добавлена в меню на экране Настройки ("Информация о приложении").
