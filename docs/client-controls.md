# Настройки и импорт после 1.1.1

- В меню добавления подписки есть импорт из буфера обмена. Поддерживаются URL подписки, ссылка импорта sing-box, ссылки на серверы, Base64 и поддерживаемые JSON/YAML-конфигурации. Каждый сервер проходит общий парсер и проверку ядром; после импорта показывается отчёт.
- Название подписки берётся из `profile-title` (в том числе `base64:`), затем из названия в JSON. Если источник не передаёт название, используется имя из ссылки или первого сервера. Заголовок `profile-update-interval` задаёт интервал в часах; приложение переводит его в минуты с диапазоном от 15 минут до недели.
- «IPv6» заменяет два пересекавшихся элемента управления. Включение добавляет IPv6-адрес туннеля и снимает блокировку; выключение оставляет IPv4 и отклоняет IPv6-трафик. Стратегии DNS задаются отдельно.
- «Трафик вне правил»: из подписки / через VPN / напрямую / блокировать. Пользовательские правила и маршруты подписки сохраняют приоритет. Явный выбор заменяет специальный маршрут «всё остальное через VPN» пресета белого списка; вариант «Из подписки» сохраняет прежнее поведение пресета.
- Обновление всех подписок запускает до четырёх задач одновременно. Результаты собираются в один отчёт в исходном порядке. Отдельные подписки также можно обновлять одновременно; повторное нажатие для уже обновляемой подписки не запускает дубликат.
- Серверы в одной группе проверяются параллельно: до десяти через активное ядро, до четырёх без VPN. Новая настройка «Тайм-аут проверки сервера» (1–60 секунд, исходно 12) ограничивает каждый сервер целиком, включая подключение и прогрев. Повторные запуски одной серии проверок блокируются до её завершения.
- Системная VPN-сессия называется SFAxtnd. Статус приложения в уведомлении — «Активно».

Сборка 1.1.2 для проверки изменений; опубликованный релиз 1.1.1 не заменяется.

## Исправления тестовой сборки 1.1.3

- XHTTP: импорт `x_padding_bytes` из ссылок; одинаковое значение в `extra` допустимо, противоречащие значения отклоняются.
- Удалённые наборы правил: ядро сначала загружает напрямую, при ошибке повторяет через прокси профиля (селектор использует выбранный сервер). Попытки ограничены 15 и 30 секундами соответственно; отмена не запускает повтор. Проверенный кеш сохраняется при неудаче обновления. Общий интервал обновлений сохранён.
- Переключение профиля: освобождается старый Android-дескриптор TUN, перезагрузки сериализуются, состояние и уведомление обновляются после завершения. Монитор сети использует физическую сеть, исключая VPN.

Содержимое пользовательских подписок и параметры доступа не входят в тестовые фикстуры. Проверка формата и параметров не означает доступность внешнего сервера в конкретной сети.
